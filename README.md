# Project-Living-Under-a-Rock-
This is a protocol to catch me up to speed after living in an information and learning blackout while the world continues normal life. Think similar to what Captain America had to do when waking up in current day after "time traveling" the hard way. 

------
History

As of the start of this project (started back in June 2026), I was a former IT Security Incident Response Senior Analyst with about 25 years IT history work. I have been relegated by court order to only allowed to have a single smartphone with monitored Internet usage. Also no work related computers with Internet usage. 

I previously had a court ordered "no Internet usage" from late September 2023 until April 2026 while being on a court ordered house arrest. This put me in a quandary... how do I keep my IT skills somewhat current, with only a smartphone? How do I learn what changed in tech after "living under a rock"? In my prior life, this would involve running a home lab, with a desktop, a NAS, docker containers, maybe some virtual machines, and maybe a cloud hosted vm, as well as daily intellectual stimulation at work.

Let's tick these off. Home lab? Limited to single smartphone with monitored Internet usage. Cloud VMs? Nope, those break the monitored rule. Daily stimulation at work? See also the "no work computers with Internet usage" limit, which limits me to a warehouse job... not exactly tech stimulation, and takes a mind used to running at 80mph and putting it on a 20mph speed limit.
